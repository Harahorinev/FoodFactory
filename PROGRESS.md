## День 1

### Учебная среда

- Компьютер: Mac с M3 Pro, архитектура arm64.
- Операционная система: macOS 15.7.7.
- Учебная версия 1С:Предприятия 8.3.27.1688 установлена и работает.

### Изученные темы

- Платформа 1С:Предприятие.
- Конфигурация.
- Информационная база.
- Конфигуратор.
- Независимость данных разных информационных баз.

### Выполненные задания

- Создана файловая информационная база `FoodFactory`.
- Создана подсистема `Склад`.
- Создан справочник `Номенклатура`:
  - стандартные реквизиты `Код` и `Наименование`;
  - реквизит `Артикул` типа `Строка` длиной 30;
  - реквизит `ЕдиницаИзмерения` типа `Строка` длиной 20.
- Справочник `Номенклатура` включён в подсистему `Склад`.
- Основная конфигурация сохранена.
- Конфигурация базы данных обновлена.
- Создан элемент справочника `Номенклатура`:
  - наименование — `Мука пшеничная`;
  - артикул — `FLOUR-001`;
  - единица измерения — `кг`.
- После повторного открытия информационной базы созданный элемент виден.

### Ошибки и уточнения

- Сначала флажок включения справочника в подсистему искался в свойствах подсистемы. Уточнено правильное расположение: страница `Подсистемы` в свойствах справочника.
- Сначала смешивались понятия подсистемы и поля, а также видимости в навигации и прав доступа. Затем различие между ними было понято.

## День 2

### Изученные темы

- Общий модуль `УтилитыFoodFactory`.
- Функции и возврат значений.
- `Массив` и цикл `Для каждого`.
- Обработка ошибок через `Попытка/Исключение`.
- `Структура` как объект результата и `Соответствие` для подсчёта значений.
- Ручной test harness в обработке `.epf`.

### Выполненные задания

- В общем модуле `УтилитыFoodFactory` реализованы функции:
  - `НормализоватьАртикул`;
  - `ПересчитатьКоличество`;
  - `НормализоватьАртикулы` без мутации входного массива;
  - `ПроанализироватьАртикулы`, возвращающая `Структура` результата и использующая `Соответствие`.
- Через ручной `.epf` test harness выполнены позитивные и негативные проверки функций.
- Создан Git-репозиторий FoodFactory.
- Выполнен публичный push репозитория.

### Ошибки и уточнения

- Допущена ошибка в имени функции определения типа: `ТипЗнач` вместо `ТипЗнч`.
- Пропускались точки с запятой.
- Конструкция `Возврат` с `=` вернула значение типа `Булево`, а не ожидаемое значение.
- `Новый Массив` был ошибочно записан как объявление.
- Допущена опечатка `Дообавить`.
- Элемент UI `Команда` был ошибочно принят за массив.
- Вместо генерации исключения возвращалась строка с описанием ошибки.
- Проверка через `Соответствие` сначала была неявной или перевёрнутой.
- Термин DTO оказался ошибкой наставника; затем результат был объяснён как `Структура` результата.
